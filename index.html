📐 Suma y Resta de Polinomios

Ejemplos resueltos y práctica guiada

➕ EJEMPLO 1: SUMA
(3x² + 2x - 5) + (x² - 4x + 7)
Resultado
4x² - 2x + 2
➕ EJEMPLO 2: SUMA
(2x² + 5x - 3) + (4x² - x + 6)
Resultado
6x² + 4x + 3
➖ EJEMPLO 1: RESTA
(5x² + 3x - 2) - (2x² + x - 4)
Resultado
3x² + 2x + 2
➖ EJEMPLO 2: RESTA
(7x² - 4x + 1) - (3x² - 2x - 5)
Resultado
4x² - 2x + 6
📝 PRÁCTICA DEL ESTUDIANTE
(x² + 3x + 2) + (2x² - x + 5)
(4x² - 5x + 1) - (x² - 2x - 3)
