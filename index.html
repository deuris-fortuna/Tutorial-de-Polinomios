📐 Suma y Resta de Polinomios

Explicación paso a paso

➕ EJEMPLO 1: SUMA
(3x² + 2x - 5) + (x² - 4x + 7)
Paso 1: Identificar términos semejantes
x²: 3x² y x²
x: 2x y -4x
Constantes: -5 y +7
Paso 2: Agrupar
(3x² + x²) + (2x - 4x) + (-5 + 7)
Paso 3: Operar
4x² - 2x + 2
✓ RESULTADO: 4x² - 2x + 2
➕ EJEMPLO 2: SUMA
(2x² + 5x - 3) + (4x² - x + 6)
Paso 1: Términos semejantes
x²: 2x² y 4x²
x: 5x y -x
Constantes: -3 y +6
Paso 2: Agrupar
(2x² + 4x²) + (5x - x) + (-3 + 6)
Paso 3: Resolver
6x² + 4x + 3
✓ RESULTADO: 6x² + 4x + 3
➖ EJEMPLO 1: RESTA
(5x² + 3x - 2) - (2x² + x - 4)
Paso 1: Cambiar signos
- (2x² + x - 4) → -2x² - x + 4
Paso 2: Agrupar
(5x² - 2x²) + (3x - x) + (-2 + 4)
Paso 3: Resolver
3x² + 2x + 2
✓ RESULTADO: 3x² + 2x + 2
➖ EJEMPLO 2: RESTA
(7x² - 4x + 1) - (3x² - 2x - 5)
Paso 1: Cambiar signos
- (3x² - 2x - 5) → -3x² + 2x + 5
Paso 2: Agrupar
(7x² - 3x²) + (-4x + 2x) + (1 + 5)
Paso 3: Resolver
4x² - 2x + 6
✓ RESULTADO: 4x² - 2x + 6
